# 📚 Bookstore Management System

A lightweight and user-friendly frontend Bookstore Management System built using **HTML, CSS, and Vanilla JavaScript**.  
This project allows users to **add, view, and remove books dynamically** through an interactive and responsive user interface.

---

## 🔍 Project Overview

The Bookstore Management System is designed to demonstrate core frontend development concepts such as **DOM manipulation**, **event handling**, and **dynamic UI updates** without using any external frameworks or libraries.

Users can:
- Add new books by entering the title, author, and description
- View added books instantly on the page
- Delete books dynamically with a single click
- Interact with a clean popup-based form interface

This project is ideal for beginners learning JavaScript and frontend fundamentals.

---

## ✨ Features

- 📖 Add book details (Title, Author, Description)
- ❌ Delete books dynamically
- 🪟 Popup modal for book entry
- ⚡ Real-time DOM updates
- 🎨 Responsive and clean UI design
- 🧩 No external libraries or frameworks used

---

## 🛠️ Tech Stack

- **HTML5** – Structure of the application  
- **CSS3** – Styling and responsive layout  
- **JavaScript (Vanilla JS)** – Logic, DOM manipulation, and event handling
